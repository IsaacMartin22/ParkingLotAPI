Parking Lot API Documentation

Base URL: Hosted on AWS ECS

This service exposes analytics, diagnostics, chat, contact, video download, and integration endpoints.

The production deployment is hosted on AWS using ECS behind the public API URL configured for this environment.

Public writes include analytics events, contact messages, and chat.

The parking application has been retired. Parking lot, floor, section, parking-space, and floor SSE endpoints are no longer available.

TikTok Video Downloads

GET /api/gubb?url=<URL-encoded HTTPS TikTok URL> queues a low-priority background job and returns HTTP 202 with jobId, status, and statusUrl. Poll GET /api/gubb/jobs/<id> every two seconds. Use the returned video url only when status is completed. Stop on failed, cancelled, or any request error. Cancel with DELETE /api/gubb/jobs/<id> if polling fails or the user stops. Jobs cancel automatically after 30 seconds without polling. The returned URL supports streaming and seeking through HTTP Range requests. Videos are publicly accessible by URL for seven days, then return 404. Downloads may take up to five minutes; expired files are deleted hourly.
